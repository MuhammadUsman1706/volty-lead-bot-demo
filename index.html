What happens behind the chat

The bot follows lead-qualification best practice: challenge before budget, five questions at most, something useful after every answer, and contact details only after it has helped.

  1. One-tap questions

    Volty's quick-path flow asks business type, main challenge, monthly customers, team size and timeline, with a matching customer result after each answer.

  2. A tailored plan

    Volty's agent takes over with the whole path and recommends the smallest plan that fits, shown as a fact card with features for their challenge.

  3. Scored and recorded

    It scores the lead out of 100, picks Hot, Warm, Nurture or Not a fit, and writes 11 custom contact fields plus a one-line summary a salesperson can act on.

  4. The right next step

    Hot leads go to the team with a form, Warm leads get the free trial, explorers get a case study, and anyone can type “human” at any time.

How it was built

Set up from Claude Code with the volty CLI: widgets create for the web chat on voltade.com, then volty init to pull the workspace into a folder, edit it as files and volty push it back.

Tested end to end: chat-flow try for the button paths, debug wake-sync --web-chat for free-text visitors, and real chats on the hosted chat page.

  • quick-paths.ts: the qualification flow (Flow: Level 1)
  • instructions.md: how the agent recommends, scores, records and hands off
  • org.md and a Drive fact sheet: pricing, features, security and customer results from voltade.com
  • Contact fields and auto-add labels for the lead data, with smart Contact Labels on
  • Hand-off topics for sales, enterprise, support and complaints
